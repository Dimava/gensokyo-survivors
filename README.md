# Gensokyo Survivors

**Play: https://dimava.github.io/gensokyo-survivors/**

A shrine maiden versus the whole of Gensokyo: a Vampire Survivors–style run with Touhou bosses and spell cards, skill cards drawn mid-fight, gacha card packs and a shrine upgrade tree. Everything (art, rigs, music) is drawn and synthesized in code in the browser.

This branch holds only the built game (build of `6d51457` (v1.0.0)).

Gensokyo Survivors is an unofficial fan work of the Touhou Project. It is not affiliated with Team Shanghai Alice. Touhou Project characters and world © ZUN / Team Shanghai Alice.
